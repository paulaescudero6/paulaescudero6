## 🚀 Proyectos

### ⭐ TFM — Máster en Ciberseguridad
**[Zero Trust Access Control — OpenSSH + Wazuh + Fail2ban](https://github.com/paulaescudero6)**

Implementación de un sistema de control de acceso basado en el modelo Zero Trust sobre entorno virtualizado Linux. MFA con TOTP (SSH + Google Authenticator), respuesta automática ante intrusiones con Fail2ban, centralización de logs con rsyslog, SIEM con Wazuh y correlación MITRE ATT&CK. Todo con herramientas open source.

`Zero Trust` `Wazuh / SIEM` `Fail2ban` `MFA · TOTP` `UFW` `rsyslog` `Linux`

---

### ⭐ Proyecto Intermodular — DAW + ASIR
**[Plataforma de simulación de phishing — Gophish + MailHog](https://github.com/paulaescudero6/ProyectoIntermodular)**

Herramienta de auditoría ética para entrenar el firewall humano de organizaciones. Simula campañas de phishing en red local aislada: correos con píxel de rastreo y URLs parametrizadas por destinatario, redirección educativa al hacer clic, y panel de resultados con métricas de riesgo. Stack: Gophish, MailHog, Tailscale, Kali Linux.

`Phishing simulado` `Ingeniería social` `Tailscale` `Gophish` `Hacking ético`
